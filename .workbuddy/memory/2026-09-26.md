## 波乐美水质方案智能平台 — 实施计划

- 需求：客户提供水样数据 + 执行标准 + 目标值 + 规模 → 平台基于波乐美（BDD 电极）真实案例输出工艺路线建议 + 设备选型 + 成本 + 方案书草稿。
- 交付物：`D:/Case Flow/波乐美水质方案智能平台_实施计划.md`（10 节完整计划）
- 核心判断：
  - 案例检索（C1）✅ 完全可行；路线推荐（C2）🟡 需人工确认；设备选型（C3）✅ 但必须用确定性公式算，禁止 LLM 算术；全自动出可签约方案 ❌ 有责任风险，不建议。
  - 最大风险 = 数据而非技术。A 级案例（有完整进出水实测）< 20 个时不做检索功能。
- 架构定案：6 层（L0 案例数据 / L1 输入校验 / L2 检索 / L3 计算 / L4 推理 / L5 输出 / L6 反馈回流）。
  - 分层原则：**C1 用数据库查，C2/C4 用 LLM 写，C3 用代码算**，三者不混在一个 Prompt。
  - 检索用「结构化硬过滤（行业+规模±50%+特征污染物）→ 加权相似度」，权重：行业 30% / 特征污染物 25% / 浓度对数距离 15% / 出水标准 10% / 规模 10% / 其他 10%。输出必带分项得分。
- 5 阶段路线图：P0 数据盘点(1~2周) → P1 案例库 MVP(2~3周,零代码) → P2 Streamlit 原型(3~5周) → P3 双引擎化(4~6周) → P4 内部上线+回流(2~3周)。内部可用版 3~4.5 个月，现金成本 < 5000 元。
- 回测验收指标：Top3 命中真实采用路线比例 ≥ 70%；选型与工程师手工核算偏差 ≤ 20%。
- 7 条关键建议：① 定位为"售前经验加速器"而非"自动设计平台" ② 输出优先对比表而非方案书 ③ 强制保留"建议小试" ④ 内置"不适配判定"（敢说"不"）⑤ 数据回流 = 唯一护城河 ⑥ 先一个行业做深 ⑦ 不做卡密/多租户（过早优化）。
- 待用户确认 5 问：历史项目数量与 A 级占比 / 资料存放格式 / 第一版使用者（售前 vs 工程师）/ 能否拿到工程师配合 / 是否单行业先行。
