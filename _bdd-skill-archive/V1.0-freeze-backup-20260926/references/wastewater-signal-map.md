# Wastewater Signal Map · 废水特征信号识别

> ⚠️ **本文件为骨架，V1 阶段只建立结构，不填入未经确认的技术判断。**
> 用途：从**询盘文字**中识别行业与废水特征信号，服务于 **BDD Relevance** 判定（8 项输入中的第 6 项 Wastewater Signals）。
> **本文件的输出是"识别到什么"，不是"水质参数是多少"。禁止输出任何数值区间。**

---

## 一、本文件的作用边界

| 做 | 不做 |
|---|---|
| 从客户描述中识别行业关键词 | ❌ 输出 COD / 氨氮等参数数值 |
| 识别废水类型关键词（如"含酚""含络合金属"） | ❌ 判断技术是否可行（那是 Technical Fit 的职责） |
| 识别"客户是否已提供水质数据" | ❌ 用行业平均值补全缺失数据 |
| 提示可能存在的干扰因素**类型**（不含量值） | ❌ 给出干扰因素的判定阈值 |

---

## 二、行业关键词 → 行业识别

用于第 1 步信息提取时，从询盘文字判断行业。

> 【待填】由 Boromond 技术/销售补充实际遇到的行业与关键词。

| 行业 | 识别关键词（中文 / 英文 / 常见误写） |
|---|---|
| 【待填】 | 【待填】 |

**识别规则**：
- 客户**自述行业** → FACT（Source：客户自述）
- 从工艺描述**推断行业** → INFERENCE（必须写 Reason）
- 无法识别 → `Unknown`

---

## 三、废水特征关键词 → 特征信号识别

用于识别客户描述中的废水特征，**只做定性标注**。

> 【待填】关键词表，以及每个特征可能对应的干扰因素类型。

| 客户描述关键词 | 特征信号（定性） | 可能涉及的干扰因素类型 |
|---|---|---|
| 【待填】例：含酚 | 酚类有机物 | 【待填】 |
| 【待填】例：含络合金属 | 重金属络合物 | 【待填】 |
| 【待填】例：高盐 | 高盐体系 | 【待填】 |
| 【待填】例：有颜色 | 高色度 | 【待填】 |
| 【待填】例：有泡沫 | 表面活性剂 | 【待填】 |

**输出格式**：只能输出信号名，例如 `特征信号：含酚类有机物`。
**禁止**：输出"含酚废水通常 COD X~Y"这类数值判断。

---

## 四、水质数据完整度检查

用于第 5 步 Missing Critical Data 的生成。

| 需要的数据 | 客户是否提供 | 未提供则列入 Missing Critical Data |
|---|---|---|
| 进水 COD 或目标污染物浓度 | | ✅ |
| 特征污染物类型 | | ✅ |
| 盐度 / 氯离子含量 | | ✅ |
| 处理水量 m³/d | | ✅ |
| 目标限值 / 执行标准 | | ✅ |
| 检测报告（CMA 资质） | | 视情况 |
| pH / SS / 色度 | | 视情况 |

**规则**：
- 客户提供的数据**必须标注来源**：`客户自述` / `检测报告` / `客户口径未经检测确认`
- 检测报告超过 6 个月 → 标注"检测时效存疑"，建议重新取样
- 无 CMA 资质报告 → 标注"数据不可直接用于设计"

## 五、待校准项

| # | 待填内容 | 归属 |
|---|---|---|
| 1 | 实际遇到过的行业清单与识别关键词 | 销售 |
| 2 | 客户描述中常见的废水特征关键词 | 销售 |
| 3 | 每个特征对应的干扰因素类型（定性即可） | 技术 |
| 4 | 哪些数据属于"必需"、哪些属于"视情况" | 技术 + 销售 |
| 5 | 客户常见的数据提供形式（自述 / 报告 / 表格） | 销售 |

---

## 六、与其他文件的职责边界

| 文件 | 负责 |
|---|---|
| **本文件** | 从文字中**识别**信号（定性） |
| `lead-signals.md` | 从外部来源**检索**证据 |
| `evidence-policy.md` | 决定识别结果标 FACT 还是 INFERENCE |
| `bdd-fit-rules.md` | 判定 **Industry Fit**（行业级） |
| `bdd-relevance-rules.md` | 判定 **BDD Relevance**（公司级，消费本文件识别出的废水信号） |

**五者不可互相替代。** 本文件识别出的特征信号是 BDD Relevance 的输入之一，也是 INFERENCE 的来源之一。

> **V1 冻结说明**：Technical Fit 判定已移出 Skill。本文件识别出的废水信号**不再用于技术适用性判断**，仅用于 BDD Relevance 的场景判定。
