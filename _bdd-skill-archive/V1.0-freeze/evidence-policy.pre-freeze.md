# Evidence Policy · 证据政策

**适用范围：所有关键外部结论。** 不限于企业信息表——每一个进入判断卡的结论都必须遵守本文件。

---

## 一、三种类型定义

| 类型 | 定义 | 强制字段 | 示例 |
|---|---|---|---|
| **FACT** | 可追溯到公开来源，或客户明确陈述 | **必须**有 `Source` | 「参保 320 人」← 来源：企业年报 |
| **INFERENCE** | 基于 FACT 的合理推断 | **必须**有 `Reason` + `Confidence` | 「废水以含酚为主」← 理由：焦化行业典型特征；置信度：Medium |
| **UNKNOWN** | 未查到 / 无法判断 | 无 | 「未查到环评公示」 |

### 三条铁律

1. **FACT 无 Source → 不得标为 FACT。** 降级为 INFERENCE（补 Reason）或 UNKNOWN。
2. **INFERENCE 无 Reason 或无 Confidence → 不得输出。**
3. **UNKNOWN 保持空白。** 不允许用行业经验值、同类客户类比、"通常来说"、"一般来说"填充。

---

## 二、Confidence 分级

**注意：Confidence 只描述 FACT 的可靠度，不描述推断强度。**

| 等级 | 定义 |
|---|---|
| **High** | 官方来源（企业信用公示、政府公示、排污许可平台、官网）+ 多条互证 |
| **Medium** | 单一可信来源（权威媒体、行业协会、上市公司公告） |
| **Low** | 第三方聚合站、B2B 平台、无日期信息、来源不可追溯 |

**Source 写法**：优先写 URL 或来源全名。客户口述写 `客户自述`。

---

## 三、FACT / INFERENCE / UNKNOWN 判定流程

```
拿到一条信息
   │
   ├─ 有可验证来源？ ──── 否 ─→ 是客户明确陈述？ ── 否 ─→ UNKNOWN
   │         │是                        │是
   │         ▼                          ▼
   │       FACT                      FACT（Source: 客户自述）
   │
   └─ 无来源，但能说明推断理由？ ── 是 ─→ INFERENCE（Reason + Confidence）
                                └─ 否 ─→ UNKNOWN
```

## 四、Demand Evidence 分级映射表

**Demand Evidence 五级只依据 FACT / INFERENCE，不依据行业好坏，不依据最终是否成交。**

| 等级 | 判据（满足任一） | 典型证据 |
|---|---|---|
| **Confirmed** | 客户明确陈述具体项目 / 采购计划，且有第三方或文件佐证 | 客户提供环评文件、招标文件；或公开中标公告 |
| **Strong Signal** | 存在硬性外部信号，但客户尚未明确项目 | 近 12 个月环保处罚记录；环评公示；排污许可变更；公开招标公告 |
| **Potential** | 只有间接信号，无明确项目 | 行业属于目标市场；招聘环保工程师；新增产线公告；扩产新闻 |
| **Weak** | 客户主动联系但无任何外部信号，且询盘内容笼统 | 只问通用价格 / 只要资料；无具体水质、水量、时间节点 |
| **Unknown** | 无足够信息判断 | 信息极少；无法检索到主体信息 |

### 定级规则

- **就低不就高。** 同时满足多个等级时取较低者。
- **不得跨级。** 只有 Industry Fit 对口 → 最高只能到 `Potential`。
- **不得用结果反推。** 「后来成交了」不构成 Confirmed 的依据；「后来没成交」也不构成 Weak 的依据。
- Confirmed 需要**文件级**证据。仅有客户口述 → 最高 `Strong Signal`。

## 五、Commercial Risk 危险信号（供定级使用）

定级只用**询盘当时可观察的事实**。

| 信号 | 风险指向 |
|---|---|
| 一上来就要技术方案和选型计算 | High |
| 反复追问电流密度、能耗、停留时间 | High |
| 拒绝提供水质数据但要求出方案 | High |
| 说"有很多项目"但拿不出具体项目 | High |
| 同时索要多份不同行业的脱敏案例 | High |
| 要求提供客户联系方式做"回访" | High |
| 邮箱域名是同行公司 | High |
| 拒绝签保密协议但坚持要案例 | High |
| 要求"先把方案发来看看，合适再谈" | Medium |
| 对价格不敏感，只对参数敏感 | Medium |
| 只问价格，不问技术 | Medium |
| 无异常信号 | Low |
| 信息不足无法判断 | Unknown |

> 完整危险信号清单见 `references/disclosure-policy.md` 第二节。

## 六、输出格式要求

### 附录 A 表格

```markdown
| # | 类型 | 结论 | Source | Reason | Confidence |
|---|---|---|---|---|---|
| 1 | FACT | 参保 320 人 | 企业年报公示 | — | High |
| 2 | INFERENCE | 废水以含酚为主 | — | 焦化行业典型特征 | Medium |
| 3 | UNKNOWN | 环评公示 | — | — | — |
```

### 混排禁令

- FACT 行不填 `Reason`；INFERENCE 行不填 `Source`（除非推断基于某个特定来源）。
- **不得把 FACT 与 INFERENCE 写在同一行或同一格。**
- **不得把 UNKNOWN 写成"可能""或许"等模糊表述。** UNKNOWN 就是 UNKNOWN。

### 可溯源率（回测指标）

```
可溯源率 = 已标注 Source 的 FACT 数 / FACT 总数
目标：100%
```

任何 FACT 缺 Source 即为不合格，回测直接判不通过。

## 七、常见错误对照

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| 「该公司年产 5 万吨」（无来源） | FACT 缺 Source | 补 Source，或降级为 INFERENCE |
| 「估计参保 100 人左右」 | 用推测冒充规模数据 | UNKNOWN |
| 「印染废水通常 COD 800~1500」 | 用行业经验值当客户数据 | UNKNOWN（Technical Fit 走 Insufficient Data） |
| 「可能正在规划环保改造」 | UNKNOWN 被包装成推断但无理由 | UNKNOWN，或补 Reason 后标 INFERENCE/Low |
| 「客户很有诚意」 | 主观判断，非证据 | 删除，或改为可观察事实（如"提供了水质检测报告"） |
| 「该行业是我们的优质市场」 | 行业属性≠客户需求 | 归入 Industry Fit，不进 Demand Evidence |

- [ ] Demand Evidence 五级的判据是否与实际一致？
- [ ] 环保处罚记录的时效窗口（现为 12 个月）是否需要调整？
- [ ] 是否需要增加其他硬信号来源（如环保督查通报、行业黑名单）？
