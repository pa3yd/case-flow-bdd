## 附录 C · 推进节奏（原文模板）

```markdown
<details>
<summary>附录 C · 推进节奏</summary>

| 时间 | 动作 |
|---|---|
| Day 0 | {回复 + 追问 X 项} |
| Day 2 | {未回复则换渠道} |
| Day 5 | {提供新价值，不催单} |
| Day 10 | {推进寄样小试} |

</details>
```

**完整版跟进节奏**（原 `reply-playbook.md` 第三节逐字）：

| 时间 | 动作 | 目的 |
|---|---|---|
| **Day 0** | 首次回复（含必问清单或寄样邀请） | 建立专业印象 + 索要参数 |
| **Day 2** | 未回复 → 换渠道触达（电话/微信/另一个联系人） | 提高触达率 |
| **Day 5** | 二次跟进，提供**新价值**（同类行业案例目录 / 技术文章） | 不催单，给东西 |
| **Day 10** | 推进寄样：明确说"免费小试、3 个工作日出报告" | 核心动作 |
| **Day 20** | 询问项目进度，提供小试方案细节 | 保持存在感 |
| **Day 30+** | 转入月度维护；有环保政策更新时定向推送 | 长期培育 |

### 二次跟进的原则（原文）

**跟进不是"问考虑得怎么样了"，而是"给你新东西"。**

可用的新价值：
- 该行业的 BDD 应用案例目录（脱敏）
- 新的环保排放标准解读（对客户有直接影响）
- 一个同类水质的处理效果数据（不含工艺参数）
- 邀请参观已建成案例现场
