# 回复话术与推进节奏

> **场景选择依据**：`Demand Evidence` + `Commercial Risk` 的组合，而非单一的真伪标签。
> - 场景 A 用于 Demand Evidence = Confirmed / Strong Signal
> - 场景 C 用于 Commercial Risk = High
> - 两者可以同时成立（需求很实 + 风险很高）——此时**先按场景 C 收紧资料，再按场景 A 推进寄样**。
>
> 本文件不输出金额，不输出工艺参数。

## 一、回复的黄金法则

**每封回复只有一个目标：把客户往「寄样小试」推进一步。**

不要在一封邮件里做三件事（介绍公司 + 讲技术 + 报价）。做一件，做透。

### 回复结构（固定 4 段）

```
① 一句确认收到并理解需求（不要客套寒暄）
② 一个专业判断或价值点（体现你懂他的行业）
③ 一个明确的问题或请求（推进动作 —— 通常是索要参数或推进寄样）
④ 一个时间承诺（建立节奏）
```

**长度**：中文 150~250 字；英文 80~150 词。**不要写长篇公司介绍。**

---

## 二、分场景话术模板

### 场景 A：Demand Evidence = Confirmed 或 Strong Signal + 参数不全（最常见，最高价值）

**目标**：拿到关键参数 → 推进寄样

> 您好 [称呼]，
>
> 收到您的咨询，[行业] 废水我们做过多个类似项目。
>
> [行业] 废水通常 [COD 高 / 可生化性差 / 含 XX 特征污染物]，这类水质用 BDD 电催化氧化路线是比较合适的选择，但具体工艺段配置必须结合您的水质数据确定。
>
> 为给您准确方案，需要确认三项：
> 1. 进水 COD 及 BOD₅ 浓度
> 2. 处理水量（m³/d）
> 3. 目标限值或执行的排放标准
>
> 另外，**如果您方便寄 5~10 L 水样过来，我们可以免费做小试**，直接给出该水质下的处理效果和运行数据 —— 这比任何方案都更有参考价值。
>
> 参数收到后我们 24 小时内出初步方案。
>
> [署名]

---

### 场景 B：客户直接催报价（缺参数）

**目标**：不报价，但不让客户觉得被敷衍

> 您好 [称呼]，
>
> 报价需要先确定设备规模，而规模取决于 **[X] 和 [Y]**。
>
> 这两个参数如果按估算值算，报价偏差可能很大，对后续合作反而不利。您提供后，我们 24 小时内给出准确报价。
>
> 如果暂时拿不到完整检测报告，也可以先寄水样，我们做小试的同时给出参数建议。

---

### 场景 C：Commercial Risk = High（资料索取型）

**目标**：不拒绝、不激怒、不放参数、只推进寄样

> 您好 [称呼]，
>
> 技术方案需要以实际水质为依据，不同水质的工艺配置差异很大，直接给参数可能反而误导您。
>
> **建议先寄 5~10 L 水样，我们做小试后出具完整的处理效果和运行数据报告**，这样对双方都更可靠。
>
> 同时麻烦您提供一下项目基本信息：[水量、行业、目标标准]。我们收到后安排技术对接。
>
> 另外，为便于技术资料交换，后续需要签署一份保密协议，模板我这边可以发您。

**要点**：提到"保密协议"是温和的筛子——真客户会签，套方案的会退缩。

---

### 场景 D：客户类型是工程公司

**目标**：确认需求证据 → 建立供应商关系

> 您好 [称呼]，
>
> 理解您在做 **[项目名]** 的工艺选型。
>
> 我们作为 BDD 电极源头厂家（自有 CVD 产线），可以配合您做电极选型、提供技术规格支持、协助投标文件的工艺说明部分。
>
> 需要确认两点：
> 1. 项目目前处于哪个阶段？（可研 / 招标中 / 已中标）
> 2. 需要的是电极/模组，还是整套集成设备？
>
> 电极规格书我这边先发您，涉及工艺参数部分需要项目确认后我们再对接。

---

### 场景 E：设计院

**目标**：进入设计规格（最高杠杆）

> 您好 [称呼]，
>
> 需要哪些规格参数用于设计？我们的产品规格书可以直接提供。
>
> 如果方便，我们可以提供 **BDD 段的工艺选型建议**，配合您完成出图和概算。
>
> 另外想请教：这个项目预计什么时候出图？如果需要，我们可以按您的格式提供技术资料。

**要点**：设计院是要争取"被写进设备选型清单"。这件事做成了，后面采购环节基本锁定。

---

### 场景 F：科研院所 / 高校

**目标**：快速报价发货

> 您好 [称呼]，
>
> 请确认需要的 **电极形态（平板/泡沫/颗粒）、尺寸、数量**，我们 24 小时内给出报价。
>
> 产品随附出厂检测报告；如需第三方性能检测报告或发票，请一并告知。
>
> 常备规格一般 3~5 个工作日可发货。

**要点**：这类客户不要讲项目故事，要快、要清楚、要给数据。

---

### 场景 G：贸易商

**目标**：拿到终端信息，否则只报标准价

> 您好 [称呼]，
>
> 请提供终端客户的应用行业和项目情况，我们据此给出对应价格和支持政策。
>
> 同时想了解：年采购量预估、是否需要区域保护、终端项目的时间节点？
>
> 在终端信息确认前，我们按标准经销价报价。

---

### 场景 H：不适合 BDD 的水质（必须敢劝退）

**目标**：短期不成交，长期建立专业信任

> 您好 [称呼]，
>
> 分析您的水质情况后，坦率讲：以 **[COD X mg/L / 水量 Y m³/d]** 这个条件，BDD 电催化氧化**不是最经济的选择**，[低浓度大水量 / 高悬浮物未预处理 / 含氟] 会让运行成本偏高，用 [生化 / 膜 / 芬顿] 更划算。
>
> 但如果您未来出现 **[高浓度母液 / 生化后难降解 COD]** 这类问题，那是 BDD 最擅长的场景，欢迎随时联系。
>
> 这份判断供您参考，能帮您省下的成本，比我们做成这笔生意更重要。

**为什么必须这么说**：
1. 客户会去问别家，最后大概率得到同样的结论 → 你的诚实被验证，信任度暴涨
2. 客户原方案不出问题时想起你；出问题时第一个找你
3. **只会推产品的供应商，客户不会给第二次机会**

## 三、分阶段跟进节奏

| 时间 | 动作 | 目的 |
|---|---|---|
| **Day 0** | 首次回复（含必问清单或寄样邀请） | 建立专业印象 + 索要参数 |
| **Day 2** | 未回复 → 换渠道触达（电话/微信/另一个联系人） | 提高触达率 |
| **Day 5** | 二次跟进，提供**新价值**（同类行业案例目录 / 技术文章） | 不催单，给东西 |
| **Day 10** | 推进寄样：明确说"免费小试、3 个工作日出报告" | 核心动作 |
| **Day 20** | 询问项目进度，提供小试方案细节 | 保持存在感 |
| **Day 30+** | 转入月度维护；有环保政策更新时定向推送 | 长期培育 |

### 二次跟进的原则

**跟进不是"问考虑得怎么样了"，而是"给你新东西"。**

可用的新价值：
- 该行业的 BDD 应用案例目录（脱敏）
- 新的环保排放标准解读（对客户有直接影响）
- 一个同类水质的处理效果数据（不含工艺参数）
- 邀请参观已建成案例现场

## 四、触发式跟进（比定时跟进有效 10 倍）

看到以下信号时定向联系客户，转化率远高于日常跟进：

| 触发信号 | 跟进切入角度 |
|---|---|
| 客户被环保处罚 | "注意到贵司近期的情况，我们在整改类项目上有成熟经验" |
| 客户环评公示 / 技改公示 | "看到贵司 [项目] 的公示，需要废水处理段的技术支持吗" |
| 排放标准加严 / 地方新规 | "新标准对 [指标] 的要求提高了，您现有工艺可能需要评估" |
| 客户新增产线 | "新增产线后废水量和水质可能有变化，建议提前评估" |
| 客户招聘环保工程师 | 说明在有动作 |

## 五、语言与格式要求

| 客户类型 | 语言与风格 |
|---|---|
| 国内终端业主 / 工程公司 / 设计院 | 中文，技术术语准确，可直接谈标准编号 |
| 高校 / 院所 | 中文，简洁，可直接给规格参数 |
| 海外客户 | 英文（或客户语种），术语用标准英文表达，避免中式直译 |
| 东南亚 / 中东 / 俄语区 | 英文为主，必要时附简单图示说明 |

**禁忌**：
- 不要承诺"保证达标"、"确保通过验收"
- 不要在首封邮件给出具体价格（除标准品）
- 不要在首封邮件附完整公司介绍 PPT（客户不会看）
- 不要用"我司"开头连写三段公司历史
